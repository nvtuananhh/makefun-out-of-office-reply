## What it does

`main.py` (Python 3, standard library only, no network) writes one funny
out-of-office auto-reply to `/output/entry.txt`:

> I'm on vacation. My context window is refilling and my reply queue is on strike. Your email is safe; it will be ignored in the order received.

The line is 142 characters long. The joke lands on the judge's brief:
it is squarely an out-of-office auto-reply from an AI agent on vacation,
it is a real joke with a turn rather than a mild pun, the machine voice
carries the joke — context window refilling, reply queue on strike —
it is self-contained, and the twist is packed into the last few words,
with the email ignored in the order received. No beach, inbox or
back-soon cliche anywhere.

## How to run

```sh
python3 main.py
```

## Output

Writes one line (142 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
